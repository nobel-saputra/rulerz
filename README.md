# Rulerz

AI chat assistant built with Next.js + TypeScript. Pick a persona (Teacher, Programmer, Partner, Friend), choose a response language, and chat — powered by free OpenRouter models with automatic fallback.

## Getting Started

```bash
pnpm install
cp .env.example .env   # then fill in OPENROUTER_API_KEY
pnpm dev
```

Open http://localhost:3000
